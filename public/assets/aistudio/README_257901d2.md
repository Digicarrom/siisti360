# Siisti360 — 333-page multilingual cleaning business website

A Finnish-first cleaning business template for Helsinki, Espoo and Vantaa, based on the UI visual language of the user's uploaded Justfinder HTML (navy sidebar, orange CTAs, teal accents and card layouts). It has 111 individually generated HTML routes per language (Finnish, Swedish and English), plus a zero-dependency Node.js application for lead capture, booking requests, moderated testimonials and a protected dashboard.

**Everything is editable source code.** Siisti360 is a demonstration brand, not a verified existing business.

## Open immediately (no installation)

1. Extract the ZIP into a folder.
2. Open `index.html` for the Finnish homepage.
3. Open `ALL_PAGES.html` to search and click all 333 route files.
4. All internal service, city, language, booking, pricing, comparison and story links are relative and work as local `file://` HTML links. Service search, estimate calculator, booking-form progression and language switching are browser-side interactions.
5. **Important:** When opened directly as HTML files, quote, booking and review forms cannot transmit or save submissions. The preview explicitly says so.

## Dynamic website: Mac / Windows / Linux

1. Install Node.js **version 20 or newer** from `https://nodejs.org/`.
2. Open Terminal (Mac), Command Prompt or PowerShell (Windows) in the extracted website folder.
3. Run `npm start`. No `npm install` is necessary (zero third-party runtime dependencies).
4. Open `http://127.0.0.1:3000/` (redirects to the Finnish homepage).
5. Open `http://127.0.0.1:3000/ALL_PAGES.html` for the 333-page route directory.
6. For admin, set a secure environment variable at launch. Example on Mac/Linux:

   ```bash
   ADMIN_TOKEN='replace-with-a-long-unique-random-secret' npm start
   ```

   Open `http://127.0.0.1:3000/admin` and enter the same token. For Windows PowerShell, set `$env:ADMIN_TOKEN='...'` before `npm start`.

   **Security:** never expose the admin token in client-side code, never commit it, and put the site behind HTTPS for public hosting. The `.env.example` describes environment variables but the application does not auto-load `.env`—configure them in your hosting environment or shell.

## Five demo pricing models

Source of truth: **`assets/pricing-engine.js`**, also loaded by the Node backend. Rates are **invented configuration examples** and are NOT the company's actual offers. Replace rates, minimum hours, included hours, add-ons and VAT assumptions before marketing the prices.

- Hourly: €43 per hour, 2-hour minimum.
- Fixed: €149/visit including 3 labour hours, plus €39 for each additional hour.
- Monthly: €189/month including 4 labour hours, plus €39 for each additional hour.
- Contract: €549/month including 12 labour hours over four visits, plus €35 for each additional labour hour.
- One-time: €179/visit including 3 labour hours, plus €49 for each additional hour.

The estimator recomputes from area, service type, price model and selected add-ons. Quote changes are deliberately represented as non-binding estimates. There is no automatic VAT or household-tax-credit calculation; verify legal/tax treatment and advertising accuracy before launch.

## Booking workflow and limitations

- Visitor selects cleaning type, city, area, optional add-ons, date, time and contact information.
- The browser shows a price estimate and available **requestable** time choices (Mon–Sat, 09:00 / 11:00 / 13:00 / 15:00; today removes past hours).
- A visitor explicitly submits a **booking request** with privacy consent. The server validates the date, slot, details and recalculates the estimate; then saves the request with status `new` in `data/leads.jsonl`.
- Booking requests appear in the admin lead dashboard and CSV export; the optional lead webhook can forward them to your CRM.
- **This is NOT a live capacity-integrated booking or payment checkout.** Time selection does not reserve a staff member. The website never displays a fake confirmation. To support instantly confirmed appointments, connect staff calendars, capacity rules and an actual payment provider; this integration is not provided in this template.

## Customer reviews

- Customers may submit a name, 1–5 rating and written review with consent.
- Reviews are stored in `data/reviews.json` with `pending` status.
- The admin dashboard can mark a review approved or rejected.
- Public testimonials API returns **approved** reviews only; the site does not fabricate testimonials or ratings.

## APIs

- `GET /api/health`
- `GET /api/booking-slots?date=YYYY-MM-DD&city=helsinki` — requestable example times; `confirmedAvailability: false`
- `POST /api/bookings` — persist a booking request
- `POST /api/leads` — persist an ordinary quote/contact lead
- `GET /api/reviews` — public approved reviews
- `POST /api/reviews` — submit review for moderation
- `GET /api/admin/leads` and `GET /api/admin/leads.csv` — require admin bearer token
- `PATCH /api/admin/leads/:id` — update lead status with admin token
- `GET /api/admin/reviews`, `PATCH /api/admin/reviews/:id` — moderate reviews with admin token
- `GET /sitemap.xml`, `GET /robots.txt`

No real payment cards are collected, and no test review data is bundled with the downloadable project.

## SEO and content

- 333 static HTML page files in the ZIP, all with independent URLs, Finnish/Swedish/English titles, descriptions, canonical URLs, language alternates and structured data.
- `SEO_STRUCTURE_333_PAGES.csv` contains the title, description, primary keyword and secondary keyword for each route.
- Set `SITE_URL` to your actual deployed domain before generating final SEO pages; the default placeholder `https://example.fi` deliberately yields `noindex`.
- The stories and promotional statements are templates. Replace the company founding story, staff certifications, verified product claims, customer testimonials, company identity, actual service area, booking rules and privacy policy before publication.
- Cleaning products: it is reasonable to emphasize appropriate professional cleaning products, manufacturer-directed use, and consideration for sensitive households. Never state that all chemicals are completely harmless without evidence.
- The commercial price comparison uses cited competitor-public pricing as checked **6 November 2026**, with links in the comparison page and expanded notes in `SEO_AUDIT_AND_SITEMAP.md`. The rates may later change or apply to different service terms.

## Deployment readiness

Before publishing, configure a real domain, HTTPS, data backups, production secrets, privacy/legal notices, actual company details and prices, staff scheduling, operational email notifications and any required cookie consent. File-based lead storage needs a persistent disk; on serverless platforms use a database instead. Never represent a requestable time as confirmed availability without a real schedule integration.
